# Leave_UI - UAT Plan

**Document ID:** UAT-LEAVEUI-001  
**Module:** ksf_Leave_UI  
**Version:** 1.0.0  

---

## 1. UAT Objectives

Verify that:
1. Employees can view their leave requests
2. Leave balance displays correctly
3. Managers see pending requests
4. Approval workflow functions correctly

## 2. Test Scenarios

| Scenario | Expected | Tester |
|----------|----------|--------|
| UAT-001: Employee views requests | Own requests displayed | Employee |
| UAT-002: Employee views balance | Correct entitlement/remaining | Employee |
| UAT-003: Manager views pending | All pending shown | Manager |
| UAT-004: Manager approves request | Status changes to approved | Manager |
| UAT-005: Manager rejects request | Status changes to rejected | Manager |
